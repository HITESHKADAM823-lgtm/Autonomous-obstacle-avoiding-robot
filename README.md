# Autonomous Obstacle Avoiding Robot

An autonomous mobile robot designed to detect obstacles and navigate its surroundings without continuous human intervention.

## Project Overview

This project focuses on developing an autonomous robot capable of detecting nearby obstacles, making navigation decisions, and controlling its movement accordingly.

## Objectives

- Develop an autonomous mobile robot.
- Detect obstacles using sensors.
- Avoid collisions automatically.
- Implement motor control and navigation logic.
- Understand practical applications of robotics and automation.
